# 🍅 番茄钟

一款简洁的桌面专注计时软件，帮助您专注工作、按时休息。

## 功能一览

| 功能 | 说明 |
|------|------|
| 番茄工作法循环 | 专注 25 分钟 → 短休息 5 分钟，每完成 4 个番茄自动进入 15 分钟长休息 |
| 到点提醒 | 响铃 + 桌面弹窗 + 任务栏闪烁，不会错过切换时机 |
| 今日统计 | 主界面实时显示今日完成的番茄数，数据自动保存、跨天清零 |
| 自定义设置 | 所有时长、长休息间隔、自动开始、响铃均可按需调整 |
| 自动循环 | 一个阶段结束后自动开始下一阶段（可在设置中关闭） |

## 使用方法

**方式一：直接运行打包好的程序（推荐）**

双击 `番茄钟.exe` 即可使用，无需安装任何环境。

**方式二：用 Python 运行源码**

```
python app.py
```

## 操作说明

- **开始 / 暂停 / 继续**：中间大按钮
- **重置**：重新开始当前阶段
- **跳过**：跳过当前阶段（跳过的专注不计入番茄数）
- **设置**：右上角按钮，可调整各项时长与提醒方式

## 数据存放位置

番茄计数与设置自动保存在：`C:\Users\您的用户名\AppData\Roaming\Pomodoro\data.json`

## 重新打包（开发者用）

```
python make_icon.py                              # 生成图标
python -m PyInstaller --onefile --windowed --noconfirm --name "番茄钟" --icon app.ico app.py
```

打包产物位于 `dist\番茄钟.exe`。
